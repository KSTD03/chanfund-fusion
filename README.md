## 方法论

```
缠论信号 → CSI300环境分类器 → 波动率仓位 → 环境依赖TP/SL
                    ↓                  ↓              ↓
               MA三线+ADX+ATR     signal/ATR²     BULL/OSC/BEAR不同退出
```

### 环境分类器（CSI300）

三层过滤器判断当前市场状态：
- **趋势方向**：MA20/60/120 三线排列
- **趋势强度**：ADX(14) > 22
- **波动率阻隔**：ATR 比率历史分位数

### 波动率仓位

仓位公式：`signal / ATR²`，低波动期自动放大仓位，高波动期自动缩小。

### 入场过滤

- 股票池：全市场日均量前 800 只
- 基本面评分：scores.parquet < 30 拒绝

## 数据依赖

1. **Qlib Parquet 数据** — A股日线 OHLCV（用于缠论信号计算）
2. **CSI300 日线数据** — `data/index_sh000300.csv`（环境分类器用）
3. **scores.parquet** — 基本面评分数据

## 已关闭的探索路径

详见 `knowledge_base/closed_paths.md`：
- ❌ 基本面评分重构（LGBM）— 与缠论收益无相关性
- ❌ 30分钟缠论 — 信号噪声放大，盈亏比 < 1.5
- ❌ 成交量过滤 — 800只池中阈值过低
- ❌ VOL_CAP单票上限 — 回撤控制需总仓位而非单票
