## 二、关键发现

### 发现 1：得分率最高的不是真实scores → 默认50分反而更好

```
v2.1 (scores偶尔命中): 收益28.05% 夏普0.18
v2.3 (全部默认50分):   收益23.70% 夏普0.11
v2.4 (100%真实scores): 收益13.03% 夏普-0.12
```

**初步判断：** `scores.parquet` 的评分模型可能与策略逻辑负相关——高评分股票未必有好的缠论信号。需要检查 scoring 模型是否存在过拟合或逻辑缺陷。

### 发现 2：环境分类器用MA规则解决了"98%震荡"问题

v2.2 的 ER 分类器（效率比率 >0.6）导致 98% 天数为震荡。改用 MA20/60 交叉 + 波动率硬保护后：
- 牛市 449 天(29%)
- 震荡 623 天(41%)
- 熊市 459 天(30%)
- 但震荡乘数 0.8 导致震荡市仓位砍了 20%，这是 v2.3→v2.4 收益下降的主因之一

### 发现 3：双前缀bug是v2.3 scores 0%的根因

数据加载 lambda `f"sh.{c}" if c[0]=="6"` 没处理 parquet 已有的 `sh.` 前缀，导致 `sh.600519` → `sz.sh.600519`。修复后命中率 100%。

### 发现 4：stats.gov.cn API 从本服务器无法直接访问

理由：IP 被拦截（`403 Forbidden`）。但 API 调用方法已封装成工具类备用。
