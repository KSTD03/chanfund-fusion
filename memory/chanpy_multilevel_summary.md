# chan.py 多级别联立分析

> 分析基准：Vespa314/chan.py (main分支)

---

## 一、多级别联立逻辑总结（<200字）

chan.py 的多级别分析通过 **多段 K 线数据库** 实现：日频、30分钟频、5分钟频等分别独立计算分型/笔/中枢。买卖点确认采用**高频验证低频**原则：日线级别出现一买信号后，不直接下单，而是等待低级别（30分钟/5分钟）出现同向底分型或小级别趋势反转作为**佐证信号**。不同级别信号冲突时，以高级别方向为主，低级别只做同向增强（不反向否定）。多级别联立不改变信号方向，只影响信号强度。

## 二、可参考代码路径

| 功能 | 文件路径 | 函数/类 | 说明 |
|:----|:--------|:-------|:----|
| 多级别管理 | `App/DataStorage.py` | `DataStorage` | 管理不同周期的 K 线数据 |
| 级别间信号传递 | `BuySellPoint/BSPointList.py` | `trigger_interval_confirm()` | 多级别确认逻辑（日线+30分钟） |
| 买卖点仲裁 | `BuySellPoint/BS_Point.py` | `BS_Point` | 买卖点类定义，含级别字段 |
| 信号配置 | `BuySellPoint/BSPointConfig.py` | `BSPointConfig` | 配置哪些级别参与联立 |

## 三、对我们的意义

**当前不需要实现多级别联立。** 原因：
1. 前期 30 分钟频验证已关闭（信号噪声大，盈亏比 < 1.5）
2. 日频已能稳定跑出夏普 0.268，多级别确认层带来的边际收益不明
3. 多级别联立会显著增加计算开销（~2x for 双频）

**如果需要未来加入**，chan.py 的 `trigger_interval_confirm()` 可以直接参考逻辑：

```
if 日线级别出现三类买点:
    if 30分钟级别出现底分型:
        信号强度 += 0.3  # 增强
    if 30分钟级别出现笔破坏:
        信号强度 += 0.2
    # 不单独以30分钟信号作为入场/拒绝条件
```
