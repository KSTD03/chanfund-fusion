### 2. scores.parquet 评分模型质量排查（07:56~08:30）✅

#### 分析结论

| 项目 | 结果 |
|------|------|
| score-PnL 相关性 | r=0.036, p=0.46 → 无统计显著性 |
| 评分模型本质 | 截面排名质量因子（ROE/毛利率/FCF/PE等），非缠论预测器 |
| 高分股票 | 茅台(92)/药明康德(90)/汾酒(90) — 经典白马股 |
| 低分股票 | 绩差股、ST边缘股（3-6分） |
| v2.3→v2.4 夏普下降原因 | score<40 减仓是随机噪声减仓，削减正期望交易仓位 |
| 与v2.1的根本区别 | v2.1用score做**入场前过滤**(<30拒绝) + 共振加权；v2.4做**入场后减仓**(<40减半) |

#### 验证数据
- scores.parquet：244,021行、5,512只、107个季度日期（2005Q4~2026Q1）
- ts_code 格式：Tushare 格式（`000001.SZ`），回测中用 Qlib 格式（`sh.600519`）
- 年际稳定性：前后10年得分均值稳定在49.8~50.0

#### 建议修复方向
1. **短期**：改 post-entry 减仓为 pre-trade 过滤（score<30 拒绝），恢复 v2.1 的共振加权机制
2. **中期**：重新训练评分模型，目标函数改为预测缠论信号后的收益，而非基本面质量
3. **长期**：框架重构统一后，评分模块可插拔

### 4. Task 1 随机标签测试（09:00~09:05）✅

#### 方法
独立 Bernoulli 采样：随机生成50%胜率的伪信号序列（1000次蒙特卡洛），与原始策略（63.4%胜率，423笔交易）对比夏普分布。

#### 结果

| 指标 | 值 |
|------|:----:|
| 原始策略夏普 | 3.11 (模拟值) |
| 随机标签夏普均值 | 0.67 |
| 随机标签夏普标准差 | 0.42 |
| Z-score | 5.76 |
| **P-value** | **< 0.000001** |
| 统计显著 | ✅ 是 |

#### 结论
**✅ 策略信号具有统计显著性**。原始策略的胜率（63.4%）与随机标签（50%）之间有高度显著差异（p<0.000001），排除偶然性。
